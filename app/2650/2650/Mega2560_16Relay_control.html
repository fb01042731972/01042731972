처음이신가요? 이 순서대로만 하시면 됩니다

아래 네 가지만 끝내면 릴레이가 움직입니다. 센서·키패드는 필요할 때만 추가하세요.

① 연결USB 케이블을 꽂고 "연결" 누르기
② 릴레이 방식HIGH형 / LOW형 고르기
③ 릴레이 핀R1~R16이 몇 번 핀인지 지정
④ 시퀀스"무엇이 눌리면 무엇이 움직인다" 정하기
연결한 장치가 있나요?

1. 연결

▼

USB 시리얼(커스텀 ASCII 펌웨어) 전용입니다. Chrome 또는 Edge 브라우저가 필요합니다(Web Serial API). 블루투스로 연결하려면? HC-05/HC-06 같은 클래식 블루투스 모듈을 보드에 배선(펌웨어의 Serial1, 핀 18/19)한 뒤 PC 블루투스 설정에서 먼저 페어링하세요. 그러면 일반 COM 포트처럼 목록에 나타나므로, 아래 Baud를 모듈 기본값(보통 9600)으로 맞추고 "연결" 버튼을 누른 뒤 포트 목록에서 그 블루투스 COM 포트를 선택하면 됩니다 — USB든 블루투스든 코드는 동일하게 동작합니다. BLE(HM-10, ESP32 BLE 등)는 COM 포트로 잡히지 않아 이 방식으로는 연결할 수 없습니다.

● 연결 안 됨

보드가 여러 대라면, 보드별로 설정(핀 매핑·시퀀스·릴레이 방식 등)을 파일로 따로 저장해두고 보드를 바꿀 때마다 불러와서 쓰세요. (지금은 브라우저 안에만 저장되어 있어서, 다른 보드 설정을 저장하면 이전 보드 설정을 덮어씁니다.)

아래 "웹 설정 초기화"는 이 브라우저에 저장된 화면 설정(핀 매핑·릴레이 이름·입력 채널·키패드·시퀀스 목록)만 지웁니다. 이미 보드(EEPROM)에 저장해둔 시퀀스나 릴레이 방식(RMODE)에는 영향이 없습니다.

2. 릴레이 작동 방식

▼

릴레이 모듈이 HIGH 신호에서 켜지는지 / LOW 신호에서 켜지는지 선택하세요. 아래 모든 ON/OFF 버튼·시퀀스 동작은 이 설정에 맞춰 자동으로 반대 신호를 보냅니다.

3. 릴레이 R1~R16 핀 지정 · 수동 시험

▼

R1~R16 각 채널을 실제로 배선한 핀 번호로 지정하세요. 아날로그 핀(A0~A15)에 연결하셨다면 아래처럼 숫자로 입력합니다: A0=54, A1=55, A2=56 ... A15=69 (Mega2560은 아날로그 핀도 디지털 핀 번호로 그대로 쓸 수 있습니다). 기본값은 A0~A15(54~69)로 채워져 있으니 실제 배선과 다르면 바꿔주세요. "적용"을 누르면 아두이노 EEPROM에 저장됩니다. 이름을 입력하면 자동 저장되며, ON/OFF 버튼으로 바로 테스트할 수 있습니다.

여기 ON/OFF 버튼은 배선 확인용 수동 시험입니다. 버튼·센서에 반응해서 자동으로 움직이게 하려면 9. 시퀀스에서 만드세요.

4. 입력 채널 (버튼 · 스위치)

▼

버튼을 디지털 핀 24, 25, 26...번 순서로 연결하신 경우 기본값이 그대로 맞습니다. (핀 20·21은 메가2560에서 I2C(SDA/SCL) 겸용이라, 나중에 I2C LCD 등을 추가할 때 충돌하지 않도록 일반 입출력 전용인 24번 이후를 기본값으로 뒀습니다.) 채널 수를 맞추고, 실제 배선과 다르면 핀 번호를 수정한 뒤 "적용"을 누르세요. 버튼은 한쪽 다리를 해당 핀에, 반대쪽 다리를 GND(그라운드)에 연결하면 됩니다(내부 풀업저항 사용, 눌렀을 때 ON으로 인식). 배선이 길어지면(수 미터 이상) 내부 풀업저항(약 20~50kΩ)이 약해서 노이즈로 오작동할 수 있으니, 그런 경우 외부에 10kΩ 풀업 저항을 달아주세요. 짧은 순간의 접점 흔들림(채터링)은 보드 펌웨어에서 자동으로 걸러줍니다(디바운스).

채널아두이노 핀 번호이름적용순서 이동

5. 4x4 키패드

▼

키패드 배선: 행(Row) 4개 핀은 키패드의 1,2,3,4번째 핀(보통 좌측부터)에, 열(Column) 4개 핀은 5,6,7,8번째 핀에 연결하세요. 정확한 핀 순서는 제품마다 다를 수 있으니, 배선 후 아래 "키 눌러보기 테스트"로 어떤 버튼이 어떤 문자로 뜨는지 직접 확인한 뒤 아래 매핑표에서 원하는 릴레이를 지정하시면 됩니다. 한 키를 계속 누르고 있어도 다른 키가 눌리지 않는 문제 없이 모든 키가 독립적으로 인식됩니다.

행(Row) 1~4열(Col) 1~4
키 → 릴레이 매핑

키패드 버튼을 누르면(짧게 한 번) 지정한 릴레이가 ON/OFF로 토글됩니다. 사용하지 않을 키는 "사용 안 함"으로 두세요.

키토글할 릴레이

숫자/문자 키(0~9, A~D)를 순서대로 누르면, 그 순서가 아래 "9. 시퀀스"에 등록된 코드와 정확히 일치하는 순간 #을 누르지 않아도 자동으로 해당 시퀀스가 실행됩니다(예: 특정 릴레이는 끄고 다른 릴레이는 켠 뒤 몇 초 후 자동으로 상태를 바꾸는 것도 시퀀스의 "지연(ms)"으로 그대로 구현됩니다). 실행되는 즉시 입력 버퍼가 비워지므로, 앞자리가 겹치는 코드(예: 123 / 124)도 이어서 각각 정상적으로 인식됩니다. #은 지금까지 누른 값을 바로 확인해보고 싶을 때 쓰는 수동 확인용으로 남겨뒀습니다(없어도 됨). *는 입력 중인 코드를 취소합니다. 8초 동안 다음 키가 없으면 자동으로 취소됩니다.
※ 주의: "12"와 "123"처럼 한 코드가 다른 코드의 앞부분과 완전히 같으면, 짧은 쪽("12")이 먼저 자동 실행되어 버려 "123"까지 이어서 누를 수 없습니다. 코드를 등록할 때는 서로 다른 코드끼리 앞자리가 겹치지 않도록(자릿수를 통일하거나 시작 숫자를 다르게) 정해주세요.

키 눌러보기 / 코드 입력 상태 연결된 상태에서 키패드를 눌러보면 아래에 표시됩니다.
아직 눌린 키 없음
키패드를 사용하지 않도록 설정되어 있습니다. 키패드를 연결하셨다면 위 체크박스를 켜세요.

6. 초음파 거리센서(HC-SR04)

▼

TRIG(발신 펄스)+ECHO(반사파 수신) 2핀짜리 일반 HC-SR04류를 최대 4채널까지 연결할 수 있습니다. TRIG와 ECHO에 같은 핀 번호를 넣으면 SIG 1핀형(TRIG/ECHO 통합) 모듈로 동작해서 핀을 1개만 씁니다 — 남는 핀이 부족하면 이 방식을 권장합니다. 측정은 초음파 왕복 시간을 재는 원리상 순간적으로 수~수십ms가 걸리므로, 버튼을 누르거나 자동 새로고침이 도는 동안만 짧게 걸리고 평소엔 다른 동작(릴레이·시퀀스 등)을 막지 않습니다. 각 채널 카드 아래쪽 "거리 도달 시 릴레이 작동"에서 목표 거리(cm)에 도달하면 원하는 릴레이를 자동으로 켜거나 끄도록 설정할 수 있습니다(단, "거리 자동 새로고침"을 켜둔 상태에서 PC가 연결되어 있어야 감시됩니다).

각 채널의 "거리 도달 시 릴레이 작동"은 이 컴퓨터가 켜져 있고 연결되어 있을 때만 동작하는 간이 기능입니다. 컴퓨터 없이 보드 혼자 돌리려면 같은 조건을 9. 시퀀스에서 "초음파 거리 도달" 트리거로 만들어 "보드에 저장"하세요.

7. 로드셀(HX711 무게센서)

▼

HX711 앰프 모듈(DOUT+SCK 2핀)을 최대 4채널까지 연결할 수 있습니다. 라이브러리 설치 없이 동작합니다. 사용 순서: ① 아래에서 DOUT/SCK 핀을 지정하고 "전체 적용" ② 저울 위를 비운 상태에서 "0점(태어)" ③ 무게를 알고 있는 물건을 올린 뒤 그 무게(g)를 입력하고 "보정"을 누르면 그 시점부터 실제 그램 단위로 값이 나옵니다. 보정값(0점·스케일)은 보드(EEPROM)에 저장되어 컴퓨터를 꺼도 유지됩니다. "9. 시퀀스"에서 "로드셀 무게 도달"을 트리거로 선택하면, 초음파처럼 목표 무게(g)에 도달했을 때 릴레이를 자동으로 켜거나 끄도록 컴퓨터 없이(보드 단독으로도) 설정할 수 있습니다.

8. 스텝모터

▼

STEP/DIR(+선택적으로 EN) 3선짜리 스텝모터 드라이버(A4988·DRV8825·TMC2208/2209류)를 최대 6채널까지 연결할 수 있습니다. 다만 릴레이 16개·입력채널·키패드가 이미 대부분의 핀을 쓰고 있으므로, 실제로 몇 채널까지 쓸 수 있는지는 남은 핀 수에 달려있습니다 — 아래에 핀 번호를 입력하면 다른 용도와 겹치는지 즉시 빨간색으로 알려주고, "12. 배선도"에도 함께 표시됩니다. EN핀은 보드 쪽에서 active-LOW(LOW일 때 구동 활성화, HIGH일 때 비활성화)로 가정합니다 — 다른 방식의 드라이버라면 배선을 반대로 하거나 EN을 비워두고 항상 활성 상태로 쓰세요. 이 보드는 릴레이·키패드와 같은 루프에서 소프트웨어로 펄스를 만들기 때문에 정밀 CNC 가공에는 맞지 않고, 이송·인덱싱처럼 "몇 스텝만큼 이동" 수준의 단순 위치제어용입니다. 각 채널 카드 아래쪽 "위치 도달 시 릴레이 작동"에서 목표 위치(STEPZERO 기준)에 도달하면 원하는 릴레이를 자동으로 켜거나 끄도록 설정할 수 있습니다(단, "상태 자동 새로고침"을 켜둔 상태에서 PC가 연결되어 있어야 감시됩니다).

각 채널의 "위치 도달 시 릴레이 작동"도 PC 연결 중에만 동작합니다. 컴퓨터 없이 쓰려면 9. 시퀀스를 사용하세요.

9. 시퀀스 만들기

스위치 입력(또는 초음파 거리 도달·로드셀 무게 도달) → 릴레이·스텝모터를 순서대로 동작시킵니다. 시작 조건 아래의 🔒 추가 조건으로 "다른 버튼이 눌려 있을 때만" 같은 조합 조건도 붙일 수 있습니다.

💾 프리셋 (이 컴퓨터에 여러 세트 저장)

지금 화면의 시퀀스 목록을 이름 붙여 저장해두고, 나중에 원하는 세트를 골라 불러올 수 있습니다. 보드에는 자동으로 반영되지 않으며, 불러온 뒤 아래 "⚡ 전체 시퀀스를 보드에 저장"을 눌러야 보드에 들어갑니다. "보드에 저장"이나 "보드에서 불러오기" 직전에는 현재 목록이 "자동백업 …" 프리셋으로 자동 보관됩니다(최근 10개).

"파일로 저장"은 프리셋 전체를 .json 파일 하나로 내보냅니다(저장할 폴더를 직접 고를 수 있고, 다음 저장부터는 마지막으로 저장한 폴더에서 저장창이 열립니다 — Chrome/Edge). USB·다른 컴퓨터로 옮기거나 백업할 때 사용하세요. "가져오기"로 그 파일을 다시 불러올 수 있습니다.
누를 때(ON): 버튼을 누르는(또는 초음파 거리·로드셀 무게 조건에 도달하는) 그 순간에만 1번 실행 (계속 눌려 있어도/조건을 유지해도 계속 실행 안 됨)
놓을 때(OFF): 손을 떼는(또는 거리 조건에서 벗어나는) 그 순간에만 1번 실행
양쪽 다(BOTH): 도달할 때와 벗어날 때 둘 다 실행 (한 번 왕복에 총 2번 실행)
셀렉터 스위치는 "누를 때/놓을 때"를 "그 방향으로 돌리는 순간"으로 생각하시면 됩니다.
키패드에서 이 순서대로 누르면 # 없이 자동으로 실행됩니다. (다른 코드와 앞자리가 겹치지 않게 설정하세요)
cm ※ "6. 초음파" 카드에서 해당 채널의 TRIG/ECHO 핀을 먼저 지정해두세요.
g ※ "7. 로드셀" 카드에서 해당 채널의 핀 지정과 0점/보정을 먼저 마쳐두세요.
🔒 추가 조건 (인터록) 위 시작 조건이 일어나는 그 순간, 아래 채널들이 모두 지정한 상태일 때만 실행합니다.
예 1) "CH2가 눌려 있을 때 CH3을 누르면 동작" → 시작 조건 CH3 · 누를 때 + 조건 CH2 눌림
예 2) "CH2와 CH3이 눌려 있을 때 CH5를 누르면 동작" → 시작 조건 CH5 · 누를 때 + 조건 CH2 눌림, CH3 눌림 (조건 추가를 2번)
· 시작 조건(트리거)은 "누르는 순간" 한 번만 검사하고, 조건 채널은 그 순간의 상태만 봅니다. 조건 버튼은 계속 누른 채(신호가 계속 들어가는 상태)여도 되고, 조건 버튼을 누르는 것만으로는 아무것도 실행되지 않습니다.
· 조건은 모두 맞아야 실행됩니다(AND). 하나라도 안 맞으면 그 트리거는 무시되고, 조건을 맞춘 뒤 트리거를 다시 눌러야 실행됩니다.
· "눌림"은 그 입력이 ON(신호 들어옴), "뗌"은 OFF입니다. "뗌"을 쓰면 "이 버튼이 눌려 있지 않을 때만 실행" 같은 잠금도 만들 수 있습니다.
· "양쪽 다"는 그 채널이 눌려 있든 떼어져 있든 항상 통과입니다(조건 자리만 잡아두거나 잠시 무시하고 싶을 때). 보드에 저장할 때는 항상 참이라 자동으로 제외됩니다.

동작 순서 (마우스로 추가 · 순서 변경)

각 줄 왼쪽의 ⠿ 아이콘을 마우스로 누른 채 위/아래로 끌면 순서가 바뀝니다 (▲▼ 버튼도 그대로 사용 가능). 동작 종류를 "릴레이"에서 "스텝모터"로 바꾸면 그 줄의 입력칸이 바뀝니다.

※ 아래 "PC 자동 감시"는 이 컴퓨터가 켜져 있고 이 웹페이지가 연결되어 있을 때만 동작하는 테스트용입니다. 컴퓨터 없이 계속 동작시키려면 그 아래 "보드에 저장"을 사용하세요.

감시 중지됨
⚡ 독립 작동 (컴퓨터 없이)

저장된 모든 시퀀스를 보드(EEPROM)에 통째로 기록합니다. 이후에는 컴퓨터를 끄고 전원(USB 또는 외부 어댑터)만 연결해도 보드가 스스로 입력을 감시하고 자동 실행합니다. 보드 저장 용량: 최대 14개 시퀀스 × 시퀀스당 최대 12단계 (외장 I2C EEPROM(AT24C256) 필요 — 그 이상은 화면 목록에는 남지만 보드에는 처음 14개/12단계만 저장됩니다).

위 "스케치(.ino) 만들기"는 컴퓨터·웹 연결 없이 순수 아두이노 IDE로 바로 업로드할 수 있는 파일을 만듭니다(현재 화면의 핀·릴레이 방식·시퀀스 기준). 입력 채널 트리거 + 추가 조건 + 릴레이/스텝모터 동작 + 지연만 들어가며, 키패드 코드·초음파·로드셀 트리거 시퀀스는 제외됩니다(제외 목록은 만들 때 알려드립니다). 이 스케치를 올리면 보드의 웹 제어용 펌웨어는 대체되므로, 다시 웹으로 쓰려면 원래 펌웨어(.ino)를 다시 올려야 합니다.

위 "미리보기" 버튼은 보드 연결 없이도 동작하며, "보드에 저장"을 눌렀을 때 실제로 나가는 SEQCLR/SEQTRIG/SEQSTEP/SEQNAME/SEQCOUNT 명령을 그대로 텍스트 파일로 저장합니다(보드에는 아무것도 전송하지 않습니다). 저장 후 문제가 생긴다면, 이 파일을 열어서 어느 시퀀스·단계의 값(채널 번호·핀·지연시간 등)이 이상한지 먼저 확인해보세요.

10. LED 문구판 (OLED)

▼

128x64 SSD1306 OLED를 Mega2560의 하드웨어 I2C 핀(SDA=20, SCL=21)에 VCC/GND와 함께 연결하면 됩니다. 한글/영문/숫자를 섞어서 입력할 수 있고, 화면 폭에 맞춰 자동으로 줄바꿈되어 최대 3줄까지 표시됩니다(예: "가동중" , "STOP", "이상 발생"). 보드 전원이 꺼졌다 켜져도 마지막 문구가 EEPROM에서 그대로 불러와집니다. 펌웨어에 U8g2 라이브러리 설치 후 새로 업로드해야 이 기능이 동작합니다.

⚡ 자동 알림 문구 (특정 입력이 들어올 때 몇 초간 표시)

평소에는 위에서 저장한 문구를 보여주다가, 아래에서 고른 입력 채널이 지정한 상태(눌림/뗌)가 되는 그 순간 지정한 문구를 지정한 시간(초) 동안 대신 보여준 뒤 원래 문구로 자동 복귀합니다. 보드(EEPROM)에 저장되므로 컴퓨터를 꺼도 보드 전원만 있으면 스스로 감시/동작합니다.

초 동안 표시
누를 때(ON): 버튼을 누르는 그 순간에만 1번 표시가 시작됨
놓을 때(OFF): 손을 떼는(놓는) 그 순간에만 1번 표시가 시작됨

11. 테스트 · 문제 진단

▼

설정과 시퀀스를 다 만드셨다면 여기서 바로 확인해보세요. "테스트 시작"을 누른 뒤 실제 버튼(입력 채널)을 누르면, "9. 시퀀스"에 등록해둔 시퀀스 순서 그대로 트리거(입력 채널)와 그 아래 동작 순서(릴레이)가 묶여서 표시됩니다. 트리거가 켜지면 그 시퀀스 묶음 전체가 함께 켜지는 걸 한눈에 볼 수 있습니다. 이 컴퓨터가 켜져 있고 웹페이지가 연결되어 있는 동안만 동작합니다("PC 자동 감시"와 같은 기능을 이 화면에서 보기 좋게 보여주는 것입니다). 컴퓨터 없이 계속 동작시키려면 "9. 시퀀스"의 "보드에 저장" 기능을 사용하세요.

감시 중지됨
시퀀스별 동작 확인 (트리거 → 동작 순서)
핀 원시 상태 확인 (아직 채널로 등록 안 한 핀 테스트)

아직 "4. 입력 채널"에 등록하지 않은 핀도 번호만 입력하면 지금 눌려있는지(연결/배선 확인용) 바로 볼 수 있습니다. 내부적으로 해당 핀을 INPUT_PULLUP으로 설정한 뒤 읽으므로, 버튼/센서가 핀↔GND로 연결되는 구조를 가정합니다(누르면 ON으로 표시).

자동 감지 (핀 번호를 몰라도 OK)

핀 번호를 몰라도 됩니다. "자동 감지 시작"을 누른 뒤, 보드에서 확인하려는 버튼(스위치·센서)을 하나씩 눌러보세요. 어떤 핀(D몇번)이 눌렸는지 자동으로 찾아 알려주고, 이미 "4. 입력 채널"에 등록된 핀이면 몇 번 채널인지, 어떤 시퀀스의 트리거로 쓰이는지도 함께 보여줍니다. (릴레이 출력 핀과 키패드 핀은 안전을 위해 자동으로 제외되고 건드리지 않습니다.)

감지 대기 중 아님
🔧 전체 점검 (문제 자동 진단)

버튼 하나로 여유 핀 전체(등록된 입력 채널 + 아직 등록하지 않은 핀, 릴레이·키패드 핀은 자동 제외)를 한꺼번에 점검합니다. 시작을 누르면 약 3.5초 동안 아무 버튼도 누르지 말고 기다려 주세요 — 그 사이에 아무도 누르지 않았는데 값이 흔들리는 핀이 있으면 노이즈·플로팅 문제로 자동 판단해서, 원인과 구체적인 해결 방법을 화면에 바로 알려줍니다(D40이 계속 흔들려서 나타났던 것과 같은 문제를 이 버튼 하나로 미리 찾아낼 수 있습니다).

점검 대기 중
📡 실시간 모니터링 & 작동 기록

위쪽 "▶ 테스트 시작"(또는 "9. 시퀀스"의 PC 자동 감시)을 켠 상태에서 실제 기계를 연결해 직접 동작시켜 보세요. 입력 채널이 켜지고 꺼질 때, 릴레이가 실제로 움직일 때마다 시간과 함께 아래에 자동으로 기록됩니다. 같은 채널이 아주 짧은 시간 안에 반복적으로 흔들리면(사람이 그렇게 빨리 누른 게 아닌데도) 노이즈·접촉불량으로 자동 의심해서 원인과 해결 방법을 바로 카드로 보여줍니다. "테스트 시작"을 누르지 않았다면 아래는 비어 있습니다.

12. 배선도 (자동 생성)

▼

"3. 채널→핀 매핑", "4. 입력 채널", "5. 키패드"에서 정한 핀 번호를 바탕으로 배선도를 자동으로 그립니다. 카메라로 실제 전선을 보는 것은 아니고, 설정값끼리 같은 핀을 겹쳐 쓰고 있거나, 원래 다른 용도로 고정된 핀(USB 통신 0·1번, OLED/외장 EEPROM용 I2C 20·21번)을 잘못 골랐는지 검사해서 문제가 있는 곳을 빨간색으로 짚어줍니다. 다른 화면에서 핀 번호나 이름을 바꾸면 이 배선도도 자동으로 다시 그려집니다.

아직 확인 안 함
정상 배선 핀 중복 / 예약핀 충돌 핀 미지정 현재 ON (테스트/실행 중 표시)

13. 설정 전체 인쇄 / PDF 저장

▼
