1. 연결

▼

USB 시리얼(커스텀 ASCII 펌웨어) 전용입니다. Chrome 또는 Edge 브라우저가 필요합니다(Web Serial API).

● 연결 안 됨

보드가 여러 대라면, 보드별로 설정(핀 매핑·시퀀스·릴레이 방식 등)을 파일로 따로 저장해두고 보드를 바꿀 때마다 불러와서 쓰세요. (지금은 브라우저 안에만 저장되어 있어서, 다른 보드 설정을 저장하면 이전 보드 설정을 덮어씁니다.)

아래 "웹 설정 초기화"는 이 브라우저에 저장된 화면 설정(핀 매핑·릴레이 이름·입력 채널·키패드·시퀀스 목록)만 지웁니다. 이미 보드(EEPROM)에 저장해둔 시퀀스나 릴레이 방식(RMODE)에는 영향이 없습니다.

2. 릴레이 작동 방식

▼

릴레이 모듈이 HIGH 신호에서 켜지는지 / LOW 신호에서 켜지는지 선택하세요. 아래 모든 ON/OFF 버튼·시퀀스 동작은 이 설정에 맞춰 자동으로 반대 신호를 보냅니다.

3. R1 ~ R16 채널 → 실제 핀 매핑 · 수동 시험

▼

R1~R16 각 채널을 실제로 배선한 핀 번호로 지정하세요. 아날로그 핀(A0~A15)에 연결하셨다면 아래처럼 숫자로 입력합니다: A0=54, A1=55, A2=56 ... A15=69 (Mega2560은 아날로그 핀도 디지털 핀 번호로 그대로 쓸 수 있습니다). 기본값은 A0~A15(54~69)로 채워져 있으니 실제 배선과 다르면 바꿔주세요. "적용"을 누르면 아두이노 EEPROM에 저장됩니다. 이름을 입력하면 자동 저장되며, ON/OFF 버튼으로 바로 테스트할 수 있습니다.

4. 입력 채널 (버튼/스위치)

▼

버튼을 디지털 핀 24, 25, 26...번 순서로 연결하신 경우 기본값이 그대로 맞습니다. (핀 20·21은 메가2560에서 I2C(SDA/SCL) 겸용이라, 나중에 I2C LCD 등을 추가할 때 충돌하지 않도록 일반 입출력 전용인 24번 이후를 기본값으로 뒀습니다.) 채널 수를 맞추고, 실제 배선과 다르면 핀 번호를 수정한 뒤 "적용"을 누르세요. 버튼은 한쪽 다리를 해당 핀에, 반대쪽 다리를 GND(그라운드)에 연결하면 됩니다(내부 풀업저항 사용, 눌렀을 때 ON으로 인식). 배선이 길어지면(수 미터 이상) 내부 풀업저항(약 20~50kΩ)이 약해서 노이즈로 오작동할 수 있으니, 그런 경우 외부에 10kΩ 풀업 저항을 달아주세요. 짧은 순간의 접점 흔들림(채터링)은 보드 펌웨어에서 자동으로 걸러줍니다(디바운스).

채널아두이노 핀 번호이름적용순서 이동

5. 4x4 키패드 (선택)

▼

키패드 배선: 행(Row) 4개 핀은 키패드의 1,2,3,4번째 핀(보통 좌측부터)에, 열(Column) 4개 핀은 5,6,7,8번째 핀에 연결하세요. 정확한 핀 순서는 제품마다 다를 수 있으니, 배선 후 아래 "키 눌러보기 테스트"로 어떤 버튼이 어떤 문자로 뜨는지 직접 확인한 뒤 아래 매핑표에서 원하는 릴레이를 지정하시면 됩니다. 한 키를 계속 누르고 있어도 다른 키가 눌리지 않는 문제 없이 모든 키가 독립적으로 인식됩니다.

행(Row) 1~4열(Col) 1~4
키 → 릴레이 매핑

키패드 버튼을 누르면(짧게 한 번) 지정한 릴레이가 ON/OFF로 토글됩니다. 사용하지 않을 키는 "사용 안 함"으로 두세요.

키토글할 릴레이

숫자/문자 키(0~9, A~D)를 순서대로 누르면, 그 순서가 아래 "7. 시퀀스 목록"에 등록된 코드와 정확히 일치하는 순간 #을 누르지 않아도 자동으로 해당 시퀀스가 실행됩니다(예: 특정 릴레이는 끄고 다른 릴레이는 켠 뒤 몇 초 후 자동으로 상태를 바꾸는 것도 시퀀스의 "지연(ms)"으로 그대로 구현됩니다). 실행되는 즉시 입력 버퍼가 비워지므로, 앞자리가 겹치는 코드(예: 123 / 124)도 이어서 각각 정상적으로 인식됩니다. #은 지금까지 누른 값을 바로 확인해보고 싶을 때 쓰는 수동 확인용으로 남겨뒀습니다(없어도 됨). *는 입력 중인 코드를 취소합니다. 8초 동안 다음 키가 없으면 자동으로 취소됩니다.
※ 주의: "12"와 "123"처럼 한 코드가 다른 코드의 앞부분과 완전히 같으면, 짧은 쪽("12")이 먼저 자동 실행되어 버려 "123"까지 이어서 누를 수 없습니다. 코드를 등록할 때는 서로 다른 코드끼리 앞자리가 겹치지 않도록(자릿수를 통일하거나 시작 숫자를 다르게) 정해주세요.

키 눌러보기 / 코드 입력 상태 연결된 상태에서 키패드를 눌러보면 아래에 표시됩니다.
아직 눌린 키 없음
키패드를 사용하지 않도록 설정되어 있습니다. 키패드를 연결하셨다면 위 체크박스를 켜세요.

6. 시퀀스 목록

스위치 입력 → 릴레이 여러 개를 순서대로 ON/OFF 하는 동작을 만듭니다.

누를 때(ON): 버튼을 누르는 그 순간에만 1번 실행 (누르고 있어도 계속 실행 안 됨)
놓을 때(OFF): 손을 떼는(놓는) 그 순간에만 1번 실행
누를 때+놓을 때(BOTH): 누를 때와 뗄 때 둘 다 실행 (딸깍 한 번에 총 2번 실행)
셀렉터 스위치는 "누를 때/놓을 때"를 "그 방향으로 돌리는 순간"으로 생각하시면 됩니다.
키패드에서 이 순서대로 누르면 # 없이 자동으로 실행됩니다. (다른 코드와 앞자리가 겹치지 않게 설정하세요)

동작 순서 (마우스로 추가 · 순서 변경)

각 줄 왼쪽의 ⠿ 아이콘을 마우스로 누른 채 위/아래로 끌면 순서가 바뀝니다 (▲▼ 버튼도 그대로 사용 가능).

※ 아래 "PC 자동 감시"는 이 컴퓨터가 켜져 있고 이 웹페이지가 연결되어 있을 때만 동작하는 테스트용입니다. 컴퓨터 없이 계속 동작시키려면 그 아래 "보드에 저장"을 사용하세요.

감시 중지됨
⚡ 독립 작동 (컴퓨터 없이)

저장된 모든 시퀀스를 보드(EEPROM)에 통째로 기록합니다. 이후에는 컴퓨터를 끄고 전원(USB 또는 외부 어댑터)만 연결해도 보드가 스스로 입력을 감시하고 자동 실행합니다. 보드 저장 용량: 최대 50개 시퀀스 × 시퀀스당 최대 8단계 (외장 I2C EEPROM(AT24C256) 필요 — 그 이상은 화면 목록에는 남지만 보드에는 처음 50개/8단계만 저장됩니다).

통신 로그

7. LED 문구판 (OLED, 선택)

▼

128x64 SSD1306 OLED를 Mega2560의 하드웨어 I2C 핀(SDA=20, SCL=21)에 VCC/GND와 함께 연결하면 됩니다. 한글/영문/숫자를 섞어서 입력할 수 있고, 화면 폭에 맞춰 자동으로 줄바꿈되어 최대 3줄까지 표시됩니다(예: "가동중" , "STOP", "이상 발생"). 보드 전원이 꺼졌다 켜져도 마지막 문구가 EEPROM에서 그대로 불러와집니다. 펌웨어에 U8g2 라이브러리 설치 후 새로 업로드해야 이 기능이 동작합니다.

⚡ 자동 알림 문구 (특정 입력이 들어올 때 몇 초간 표시)

평소에는 위에서 저장한 문구를 보여주다가, 아래에서 고른 입력 채널이 지정한 상태(눌림/뗌)가 되는 그 순간 지정한 문구를 지정한 시간(초) 동안 대신 보여준 뒤 원래 문구로 자동 복귀합니다. 보드(EEPROM)에 저장되므로 컴퓨터를 꺼도 보드 전원만 있으면 스스로 감시/동작합니다.

초 동안 표시
누를 때(ON): 버튼을 누르는 그 순간에만 1번 표시가 시작됨
놓을 때(OFF): 손을 떼는(놓는) 그 순간에만 1번 표시가 시작됨

8. 설정 전체 인쇄 / PDF 저장

▼

지금 이 화면(브라우저)에 입력·저장되어 있는 모든 설정을 한 장의 표로 정리해서 새 창에 보여줍니다 — 어느 채널(번호)에 어떤 이름을 붙였는지, 실제 핀 번호는 몇 번인지, 시퀀스 순서와 조건, LED 문구/자동 알림까지 전부 포함됩니다. 새 창에서 바로 인쇄 대화상자가 뜨는데, "프린터" 대신 "PDF로 저장"을 선택하면 파일로 저장할 수 있습니다(별도 프로그램 설치 필요 없음).

11. 테스트 (라이브 관람)

▼

설정과 시퀀스를 다 만드셨다면 여기서 바로 확인해보세요. "테스트 시작"을 누른 뒤 실제 버튼(입력 채널)을 누르면, "6. 시퀀스"에 등록해둔 시퀀스 순서 그대로 트리거(입력 채널)와 그 아래 동작 순서(릴레이)가 묶여서 표시됩니다. 트리거가 켜지면 그 시퀀스 묶음 전체가 함께 켜지는 걸 한눈에 볼 수 있습니다. 이 컴퓨터가 켜져 있고 웹페이지가 연결되어 있는 동안만 동작합니다("PC 자동 감시"와 같은 기능을 이 화면에서 보기 좋게 보여주는 것입니다). 컴퓨터 없이 계속 동작시키려면 "6. 시퀀스"의 "보드에 저장" 기능을 사용하세요.

감시 중지됨
시퀀스별 동작 확인 (트리거 → 동작 순서)

12. 배선도 (자동 생성)

▼

"3. 채널→핀 매핑", "4. 입력 채널", "5. 키패드"에서 정한 핀 번호를 바탕으로 배선도를 자동으로 그립니다. 카메라로 실제 전선을 보는 것은 아니고, 설정값끼리 같은 핀을 겹쳐 쓰고 있거나, 원래 다른 용도로 고정된 핀(USB 통신 0·1번, OLED/외장 EEPROM용 I2C 20·21번)을 잘못 골랐는지 검사해서 문제가 있는 곳을 빨간색으로 짚어줍니다. 다른 화면에서 핀 번호나 이름을 바꾸면 이 배선도도 자동으로 다시 그려집니다.

아직 확인 안 함
정상 배선 핀 중복 / 예약핀 충돌 핀 미지정 현재 ON (테스트/실행 중 표시)
