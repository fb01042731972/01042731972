Mega2560 + 16릴레이 전용 제어 프로그램 보드: Arduino Mega 2560

1. 연결

USB 시리얼(커스텀 ASCII 펌웨어) 전용입니다. Chrome 또는 Edge 브라우저가 필요합니다(Web Serial API).

● 연결 안 됨

2. 릴레이 작동 방식

릴레이 모듈이 HIGH 신호에서 켜지는지 / LOW 신호에서 켜지는지 선택하세요. 아래 모든 ON/OFF 버튼·시퀀스 동작은 이 설정에 맞춰 자동으로 반대 신호를 보냅니다.

3. R1 ~ R16 채널 → 실제 핀 매핑

R1~R16 각 채널을 실제로 배선한 핀 번호로 지정하세요. 아날로그 핀(A0~A15)에 연결하셨다면 아래처럼 숫자로 입력합니다: A0=54, A1=55, A2=56 ... A15=69 (Mega2560은 아날로그 핀도 디지털 핀 번호로 그대로 쓸 수 있습니다). 기본값은 A0~A15(54~69)로 채워져 있으니 실제 배선과 다르면 바꿔주세요. "적용"을 누르면 아두이노 EEPROM에 저장됩니다.

채널실제 핀 번호적용

4. R1 ~ R16 수동 시험

각 릴레이의 이름을 입력하면 자동 저장되며, ON/OFF 버튼으로 바로 테스트할 수 있습니다.

5. 입력 채널 (버튼/스위치)

버튼을 디지털 핀 24, 25, 26...번 순서로 연결하신 경우 기본값이 그대로 맞습니다. (핀 20·21은 메가2560에서 I2C(SDA/SCL) 겸용이라, 나중에 I2C LCD 등을 추가할 때 충돌하지 않도록 일반 입출력 전용인 24번 이후를 기본값으로 뒀습니다.) 채널 수를 맞추고, 실제 배선과 다르면 핀 번호를 수정한 뒤 "적용"을 누르세요. 버튼은 한쪽 다리를 해당 핀에, 반대쪽 다리를 GND(그라운드)에 연결하면 됩니다(내부 풀업저항 사용, 눌렀을 때 ON으로 인식). 배선이 길어지면(수 미터 이상) 내부 풀업저항(약 20~50kΩ)이 약해서 노이즈로 오작동할 수 있으니, 그런 경우 외부에 10kΩ 풀업 저항을 달아주세요. 짧은 순간의 접점 흔들림(채터링)은 보드 펌웨어에서 자동으로 걸러줍니다(디바운스).

채널아두이노 핀 번호이름적용

6. 4x4 키패드 (선택)

키패드 배선: 행(Row) 4개 핀은 키패드의 1,2,3,4번째 핀(보통 좌측부터)에, 열(Column) 4개 핀은 5,6,7,8번째 핀에 연결하세요. 정확한 핀 순서는 제품마다 다를 수 있으니, 배선 후 아래 "키 눌러보기 테스트"로 어떤 버튼이 어떤 문자로 뜨는지 직접 확인한 뒤 아래 매핑표에서 원하는 릴레이를 지정하시면 됩니다. 한 키를 계속 누르고 있어도 다른 키가 눌리지 않는 문제 없이 모든 키가 독립적으로 인식됩니다.

행(Row) 1~4열(Col) 1~4
키 → 릴레이 매핑

키패드 버튼을 누르면(짧게 한 번) 지정한 릴레이가 ON/OFF로 토글됩니다. 사용하지 않을 키는 "사용 안 함"으로 두세요.

키토글할 릴레이

숫자/문자 키(0~9, A~D)를 순서대로 눌러 코드를 입력한 뒤 #을 누르면, 아래 "7. 시퀀스 목록"에서 시작 조건을 "키패드 코드 입력"으로 지정하고 같은 코드를 등록해 둔 시퀀스가 실행됩니다(예: 특정 릴레이는 끄고 다른 릴레이는 켠 뒤 몇 초 후 자동으로 상태를 바꾸는 것도 시퀀스의 "지연(ms)"으로 그대로 구현됩니다). *는 입력 중인 코드를 취소합니다. 8초 동안 다음 키가 없으면 자동으로 취소됩니다.

키 눌러보기 / 코드 입력 상태 연결된 상태에서 키패드를 눌러보면 아래에 표시됩니다.
아직 눌린 키 없음

7. 시퀀스 목록

스위치 입력 → 릴레이 여러 개를 순서대로 ON/OFF 하는 동작을 만듭니다.

키패드에서 이 순서대로 누르고 #을 누르면 실행됩니다.

동작 순서 (마우스로 추가 · 순서 변경)

※ 아래 "PC 자동 감시"는 이 컴퓨터가 켜져 있고 이 웹페이지가 연결되어 있을 때만 동작하는 테스트용입니다. 컴퓨터 없이 계속 동작시키려면 그 아래 "보드에 저장"을 사용하세요.

감시 중지됨
⚡ 독립 작동 (컴퓨터 없이)

저장된 모든 시퀀스를 보드(EEPROM)에 통째로 기록합니다. 이후에는 컴퓨터를 끄고 전원(USB 또는 외부 어댑터)만 연결해도 보드가 스스로 입력을 감시하고 자동 실행합니다. 보드 저장 용량: 최대 8개 시퀀스 × 시퀀스당 최대 8단계 (그 이상은 화면 목록에는 남지만 보드에는 처음 8개/8단계만 저장됩니다).
