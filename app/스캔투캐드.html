2. 단위 / 감도 설정

값이 작을수록 완만한 곡면도 모서리로 잡습니다. 각지고 평평한 판금 부품은 15~25° 권장.

3. 평면 자동 인식

평면, 판금 절곡면 등을 자동으로 찾아 실측 치수를 계산합니다. 곡면(원통·자유곡면)은 아래 측정 도구를 사용하세요.
아직 인식된 평면이 없습니다.

4. 직접 측정 도구

모델 위 표면을 클릭해서 정확한 거리 또는 구멍/원통 지름을 직접 잴 수 있습니다. 곡면 형상에 유용합니다.

5. DXF 내보내기

저장된 DXF는 AutoCAD 등에서 바로 열립니다. DWG가 필요하면 무료 프로그램 ODA File Converter로 변환하세요 (하단 안내 참고).
