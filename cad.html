사용 설명 ✕
⚠ 사면 절곡 주의사항
  • 1t: 사면 절곡 높이(세워 올리는 면의 높이)는 최대 150까지 가능합니다.
  • 1t 초과: 사면 절곡 높이 120이 한계입니다.
  • 절곡 높이가 위 한계를 넘으면 한 장으로 사면 절곡이 어려우므로, 절단 후 용접으로 제작해야 합니다.
3D 솔리드 DXF: 한 파일에 3D 솔리드가 여러 개여도 전부 전개해서 파일 1개씩 목록에 올립니다. 전개되지 않은 솔리드는 사유와 함께 알려 줍니다. K-factor는 한 번만 묻습니다. 원뿔대(호퍼)는 중립면(안쪽에서 K×두께) 기준 부채꼴로 펴지며, 이음부에 틈이 있으면 그만큼 각도가 줄어듭니다.

파일 / 정리: 추가한 도면은 한 화면에 함께 표시됩니다. 도면 위를 드래그하면 형상(윤곽+구멍)이 통째로, 글씨는 따로 움직입니다. Alt+드래그: 선 하나만 · Alt+Shift+드래그: 파일 전체 · Shift 누른 채 이동: 가로/세로 직선으로만 이동.

☰ 손잡이로 목록 순서/폴더 정리, 이름 더블클릭: 이름 변경, 🧩: 네스팅 부품 추가.

원본 글씨 수정: 도면에 있는 원래 텍스트(주황/회색 글씨)를 더블클릭하면 바로 내용을 고칠 수 있습니다.

원/선/호 치수 확인·수정: 원, 선, 모서리 연결부의 호(Arc)를 한 번 클릭하면 반지름·길이가 표시되고, 더블클릭하면 값을 바로 바꿀 수 있습니다.

필렛 / 모따기: 홈 탭의 필렛(모서리 둥글게)·모따기(모서리 비스듬히)를 누르고 직선 2개를 차례로 클릭하세요. 클릭한 쪽이 남고 반대쪽은 접점까지 잘리거나 모서리까지 연장됩니다. 버튼 아래 ▾ 에서 반지름/거리를 바꿀 수 있고, Esc 로 끝냅니다. 선과 폴리라인의 직선 구간만 가능하며(호·원·스플라인 제외), 폴리라인은 직선 단위로 분해되어 DXF에 LINE/ARC 로 저장됩니다.

그리기(그리기 탭): 선·원·호(3점)·직사각형·슬롯·점. 끝점/중점/중심에 자석처럼 붙고(스냅), 그리는 중 숫자를 치면 길이·반지름·가로,세로를 정확히 넣을 수 있습니다. 새 도형은 선택한 도면층으로 저장됩니다.

곡선 편집(홈 탭): 연속 필렛(모든 모서리 한 번에), 파워 트림(교차점 사이를 클릭해 자르기), 옵셋(평행 복사). 치수(치수 탭): 빠른 치수·직선·각도·반경/직경·전개 길이는 주석 글씨로 기입됩니다.

선/원/호/폴리라인/점/텍스트 등 삭제: 도면의 도형을 클릭해 선택한 뒤, 왼쪽 "선택한 도형 삭제" 버튼을 누르거나 Delete 키를 누르면 삭제됩니다. DXF로 저장하면 삭제된 도형은 실제로 파일에서도 제거됩니다.

선택·이동: 마우스 왼쪽 버튼으로 도형(또는 형상 안쪽)을 끌면 그 형상(윤곽+구멍+절곡선)이 선택되어 통째로 움직입니다. 글씨는 따로 움직입니다. 빈 곳을 왼쪽 버튼으로 끌면 영역 선택(왼→오른쪽: 완전히 포함된 것만 / 오른→왼쪽: 걸치는 것 모두)이 되고, 선택된 것을 끌면 함께 움직이며 Delete로 삭제됩니다. Ctrl+클릭/드래그는 선택 추가, Alt+드래그는 도형 하나만, Alt+Shift+드래그는 파일 전체, Shift를 누른 채 이동하면 가로/세로 직선으로만 이동, Esc는 선택 해제입니다.

화면 이동: 마우스 오른쪽 버튼(또는 휠 버튼)을 누른 채 드래그합니다.

선택/이동: 주석을 클릭해 선택, 드래그로 이동, 더블클릭으로 내용 수정, 선택 후 Delete 키로 삭제.
